# Team Guide

## Project Workflow

The project follows an incremental Sprint-based development process.

Each Sprint should:

- Focus on a single engineering objective.
- Produce working and documented deliverables.
- Update the project documentation.
- Record important engineering decisions.

---

## Coding Standards

- Follow PEP 8.
- Use meaningful variable names.
- Write reusable functions whenever possible.
- Keep notebooks organized and well documented.

---

## Documentation Rules

Each completed Sprint must update:

- README.md
- PROJECT_JOURNAL.md
- CHANGELOG.md
- sprint_xx.md

---

## Git Workflow

Each Sprint should end with a dedicated Git commit describing the completed work.
