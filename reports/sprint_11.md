# Sprint 11 — Error Analysis

## Objective

Investigate model prediction errors and identify customer characteristics associated with incorrect classifications.

## Tasks

- Generated prediction analysis table.
- Categorized predictions into TP, TN, FP, and FN.
- Compared customer characteristics between correct and incorrect predictions.
- Visualized error patterns.
- Performed engineering analysis.
- Documented key findings.

## Deliverables

- Prediction Analysis Table
- Error Analysis
- Feature Comparison
- Error Visualizations
- Sprint Documentation

## Outcome

The analysis revealed that prediction errors occur more frequently among customers with shorter tenure, higher monthly charges, and month-to-month contracts. These findings highlight opportunities for future feature engineering and dataset enhancement.
